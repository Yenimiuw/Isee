# Setup guide

## SETUP GUIDE

1. install the ***Isee.zip***, extract it, and unpack it to the extension manager in your browser.
2. Open the website: (if the website doesn't open and there any problems with the websites functions kindly contact the website admin.)
```
https://isee-frontend.vercel.app
```

3. **Student | Teacher login/registration.**
    * IF you are a student and you don't have an account, then simply register.
    * IF you are a teacher request an account from the admin of the website.
    ```
    daniellepauleen2@gmail.com
    ```

## NAVIGATING

Skip to the sections in accordance with your role in the class.

***NOTE FOR TEACHERS: ENSURE THAT ALL YOUR STUDENT DOWNLOADS THE EXTENSION***

### Teacher
1. You can create a course and give the course code and password to your student so they can join your class.
2. You will then need to register a gmeet link so that the extension can track your students when they join the meeting with an extension.
3. Click their profile or click one of your student's name to see analytics about them.

### Student
1. You can join a course using a course code and a password provided to you by the professor.
2. Simply click a meeting link in the course, and the extension will automatically track your actions.
